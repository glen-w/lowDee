Type: GUIDE
Authority: Where a teacher folder sits on this machine. What may ship in a pack is decided in [CONCEPT.md](../CONCEPT.md). How the loader treats that folder is in [ARCHITECTURE.md](../ARCHITECTURE.md).

A folder a teacher wrote can live here, one pack per directory, the same manifest shape as `pack/`.
The app loads it on this machine. It does not upload a take.
The loader accepts a tune here on the same terms as `pack/`: `rights` `pd` and a named source, or `page_only` with no notes and no audio.
