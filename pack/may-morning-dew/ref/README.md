# Reference audio

Hear plays a file when it exists. When it does not, Hear plays the pack’s notes as plain tones.
The hole picture still shows. The tones are not a whistle to copy.

Held notes, already here (first six seconds, one channel):

- `D4.wav` … `B4.wav` — staircase, and low D on the first sound
- `D5.wav` — the octave on the same fingering

These are held notes from a real low D. Guy Rowland recorded his own whistle and posted it on [VI-Control](https://vi-control.net/community/threads/irish-low-whistle-vi-needed.153881/) (“Feel free to edit and use however you want”). John Green packed that into [Low-D-Whistle.dslibrary](https://drive.google.com/file/d/1ovF6i29BDtTx401RMBR3zhMOZZtioyTm/view); the pack’s note also names Tremendouz. Volume was already leveled there. Pitch is that whistle’s, a few hertz flat of concert D. The learner’s calibration still comes from their own hold.
