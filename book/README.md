# The book’s tracks

The companion recordings for *The Low Whistle Book* (Steáfán Hannigan and David Ledsam) are at [publishing.hobgoblin.com/low-whistle](https://publishing.hobgoblin.com/low-whistle/).

Put a copy in this folder if you have the book. The mp3s stay on this machine. Git ignores them. `tracks.json` names which file belongs to which step, and the passages where the whistle is playing.

Hear plays that file when it is here. A step with several files plays them in order. Skip the talk, in settings, jumps to the passage for that step. Play the talk too hears the file from the start. A build does not bundle the recordings.

*The May Morning Dew* and *As I Roved Out* are not on that page. The door’s cut and tap are the passages in the rolls introduction that name each one. The roll on A plays that introduction, then both takes. The octave on the door is the all-closed fingering, the second octave track, through the two high notes. Low D on that same lesson stays the held note.
